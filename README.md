# HIIT Kraft 30

30-Minuten-Heimtraining mit zwei Kurzhanteln (bis 15 kg): Timer, 3D-Figur zur Übungsausführung, Wiederholungs- und Gewichtsprotokoll mit Fortschrittsvergleich.

- `index.html` – App (Tag A / Tag B, Einstiegswochen, Finisher, Verlauf)
- `rig.js` – 3D-Figur und Bewegungsposen (Three.js r128 von cdnjs)

Daten liegen im localStorage des Browsers. Hosting über GitHub Pages.
